# 格点向量场模拟
> 一个向量场可视化小玩具，**不具备任何科研价值**

[English](README.md) | [简体中文](README.zh-CN.md)

## 项目介绍
这只是我随手写的一个可视化小玩具，图一乐而已。
没有严谨推导、没有合规边界条件、没有同行评审，千万别拿去写论文引用。

初衷很简单：基于格点渲染向量场，直观地玩一些有意思的物理现象。
目前在尝试模拟类引力波图案、梯度场、局部摄动扰动等效果。

很多地方物理上并不严格，不少效果只是“看着像那么回事”的近似。
这个项目优先保证视觉好玩，而不是严格符合物理定律。

## 后续计划（纯许愿清单，没有交付时间）
- 增加更多可调节物理参数，支持交互式调参
- 尝试实现弯曲时空、相对论空间相关效果（这部分大概率会写得很魔改）
- 扩充场类型：涡旋、源汇、波干涉、混沌摄动等
- 优化交互界面，实时滑块、截图导出功能
- 增加粒子追踪，演示测试质点在场里的运动
- 随缘更新，说不定哪天玩腻了就搁置跑路😂
