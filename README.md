# Lattice Vector Field Simulation
> A tiny vector field sandbox, **NOT for serious research**.

[English](README.md) | [简体中文](README.zh-CN.md)

## About this project
This is just a silly little visualization toy I built for fun.
No rigorous derivation, no correct boundary conditions, no peer review — don’t cite this in your paper, please.

My original idea is simple: visualize lattice-based vector fields and play with interesting physical phenomena in a intuitive way.
Right now I’m messing around with things like gravitational wave-like patterns, gradient fields, small perturbations and local disturbances.

I know many of these implementations are physically inaccurate. Some effects are just “looks similar” artistic approximations.
The priority is visual fun, not strict physical correctness.

## Roadmap (pure wishlist, no ETA)
- Add more tunable physical parameters, let users tweak fields interactively
- Try implementing curved spacetime / relativistic lattice effects (this one will be super hacky)
- More field types: vortex, source-sink, wave interference, chaotic perturbations
- Better UI, real-time parameter sliders, snapshot & export
- Maybe add particle tracing to show how test objects drift inside the field
- Who knows, I might abandon it halfway if I get bored 😂
